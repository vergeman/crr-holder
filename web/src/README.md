# Data access

The request flow is:

`React components → TanStack Query hooks → provider → generated HTTP client → API`

- `data/hooks.js` contains the handwritten TanStack Query hooks. They manage
  query keys, caching, and loading/error states through the selected provider.
- `data/provider.js` selects the data-access implementation. Today it calls the
  generated HTTP client and unwraps responses. Swap this provider for browser
  SQLite or VFS in Sprint 5 while keeping the same methods and response shapes.
- `generated/client.ts` contains HTTP functions and types generated by Orval
  from FastAPI's OpenAPI schema. Do not edit it by hand. The development script
  regenerates it at startup and when the schema changes.

Keep components and hooks independent of the HTTP client. Handwritten code stays
outside `generated/` so regeneration cannot overwrite it.
